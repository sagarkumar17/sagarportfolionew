# UI audio

Synthesized, royalty-free short cues for the portfolio sound layer (inspired by [gowthamganesan.com](https://www.gowthamganesan.com/)).

| File | Role |
|------|------|
| `click.mp3` | Soft UI click (nav / controls) |
| `whoosh.mp3` | Soft whoosh (enable confirm / transitions) |
| `ambient.mp3` | Quiet looped pad while sound is on |

Default: **muted**. Toggle lives in the nav next to theme.
